# Stat prices

Generated from `Config/StatPrices.luau`. All 8 stats share one price: it depends on the attribute level (total points bought) and
on the Rebirths, not on which stat is bought.

Price = 15 x 1.105 ^ level x rebirth multiplier, rounded. The server computes it.

**The real Gold bonus is not +10%.** It is additive on the base (`RebirthShop.rebirthGoldBonus`): +50% for the first Rebirth, up to
+100% for the 12th, a total of x10. So the Gold gain of Rebirth r is its real step, multiplier(r) / multiplier(r - 1) - 1, and
the price step is that gain minus 5 points, compounded, never below 0.
