 1. PORTAL RULE (do this first, small)
---------------------------------------------------------------------
 - Walking into a hub portal `workspace.Hub.Portals.Portal_<ZoneId>` teleports the player
   **directly to the Entrance of sub-zone 1 of that zone**:

 PART A - TRAINING WINDOW: ATTRIBUTES (Elden Ring style)
=====================================================================
Replaces the 6 "stats" of DESIGN.md section 3. Profile field `Stats` becomes
`Attributes = { Vigor=0, Mind=0, Endurance=0, Strength=0, Dexterity=0, Intelligence=0,
Faith=0, Arcane=0 }` (each is the number of points bought). All config in
`Config/Attributes.luau`; all derived numbers in the shared `Util/Stats.compute` (server and
client identical).

A1. RULES
 - 8 attributes, each 0..40 points. Points are bought with **Gold**, one at a time (no XP, no level).
 - **Soft cap like Elden Ring:** effective points `Peff(p) = min(p, 20) + 0.5 x max(0, p - 20)`
   (so 40 points = 30 effective points).
 - **Total points** `L` = sum of all 8 attributes (max 320). Shown as "Attribute Level: L".
 - Cost of the next point: `PointCost(L, Z) = round(100 x 10^(Z-1) x (1 + L/10)^1.5)`
   where Z = highest zone unlocked (1..12). Examples: Z1: L0 -> 100, L10 -> 283, L100 -> 3,648,
   L319 -> 18,870 (multiplied by 10 for each higher zone).
 - **Rebirth:** all points reset to 0 at Rebirth (DESIGN.md section 4). Each Rebirth makes every
   per-point effect stronger: `RebirthPower = 1 + 0.25 x Rebirths`. It multiplies the per-point values
   below EXCEPT the hard-capped values (hard caps are absolute).
 - **Respec:** a button resets all points to 0 (Gold is NOT refunded). Cost = `5 + 2 x Z` Diamonds,
   with a confirmation popup.

A2. EFFECTS PER EFFECTIVE POINT (before RebirthPower; values apply to Peff)
 | Attribute | Effects |
 |---|---|
 | Vigor | Max HP +4% ; HP regeneration out of combat +0.05% of Max HP per second (starts 5 s after the last damage) |
 | Mind | Gold Gain +2.5% ; Roll cooldown -0.7% (base 1.5 s, hard floor 0.6 s) |
 | Endurance | Defense +1.0 point ; Block reduction +0.5 percentage points (base 60%, hard cap 85%) ; Move speed +0.4% (hard cap +40% in total with pets) |
 | Strength | Weapon damage scaling (A3) |
 | Dexterity | Weapon damage scaling (A3) ; Attack speed +0.3% (hard cap +15%) |
 | Intelligence | Weapon damage scaling (A3) ; Element proc chance +0.4 percentage points (hard cap +16 pp) ; Magic area radius +0.5% (hard cap +25%) |
 | Faith | Pet bonus effectiveness +1.2% ; Lifesteal and healing effects +1.5% |
 | Arcane | Crit chance +0.25 percentage points (base 5%, hard cap 60%) ; Crit damage +1.5% (base x2.0) ; Loot drop chance +0.5% (multiplicative on base chances) |

A3. WEAPON DAMAGE SCALING (by weapon category, like Elden Ring)
 `AttributeDamageMult = 1 + 0.03 x RebirthPower x sum( weight_attr x Peff_attr )`
 | Category | Strength | Dexterity | Intelligence | Arcane | Grade shown in UI |
 |---|---|---|---|---|---|
 | Sword | 0.6 | 0.6 | - | - | B / B |
 | Spear | 0.5 | 0.7 | - | - | B / A |
 | Heavy | 1.2 | - | - | - | S |
 | Dagger | - | 0.8 | - | 0.4 | A / C |
 | Gauntlet | 0.7 | 0.5 | - | - | A / B |
 | Ranged | - | 1.2 | - | - | S |
 | Magic | - | - | 1.2 | - | S |
 | Whip & Chain | - | 0.6 | - | 0.6 | B / B |
 Grade letters from the weight: >= 1.0 S, 0.7-0.99 A, 0.5-0.69 B, 0.3-0.49 C, below D.
 Faith has no damage scaling; Vigor/Mind/Endurance have none either.

A4. HOW THE PIECES COMBINE (put this exactly in `Util/Stats.compute`)
 - MaxHP = (100 + sum of armor HP) x (1 + 0.04 x RP x Peff_Vigor + petHP% + 0.10 x HealthBoostLevel
           + setBonus 0.10) ; armor HP already includes its Zone Boost.
 - DefensePoints = (sum of armor Defense + 1.0 x RP x Peff_Endurance) x (1 + petDefense%)
 - DamagePerHit = weaponDamage(zone base x category x rarity x (1 + ZoneBoost)) x AttributeDamageMult
                  x (1 + petAttack% + 0.10 x DamageBoostLevel) x (crit ? CritDamage : 1)
 - Damage taken = raw x (1 - blockReduction if blocking) x (1 - Def / (Def + 100))
 - Gold gain multiplier = (1 + 0.025 x RP x Peff_Mind + petGold% + 0.10 x GoldBoostLevel + boosts)
                          x (1 + sum of Rebirth multiplier bonuses)
 - Pet percentages are multiplied by `(1 + 0.012 x RP x Peff_Faith)` before use.
 - Apply every hard cap listed in A2 at the end.
 Write a test script (admin command `runStatsTests`) with 5 sample profiles and expected results.

A5. THE WINDOW ("Training" button), inspired by the Elden Ring status screen
 - Wood-fantasy panel. Header "Attributes", "Attribute Level: L / 320", Gold available.
 - **Left: 8 rows** (3D icon, name, current points big, a bar up to 40 with a visible marker at the soft
   cap 20, [-] and [+] buttons). [+] adds a PENDING point (cost shown), [-] removes only pending points.
   Pending values show as `12 -> 15` in green. Hold [+]/[-] to repeat. Tap/hold an attribute name for a
   tooltip listing its effects.
 - **Right: "Status" list** with `before -> after` (green when better): Max HP, HP regen, Defense and
   damage reduction %, Block reduction, Move speed, Roll cooldown, Attack speed, Gold gain, Crit chance,
   Crit damage, Loot luck, Element proc, Magic radius, Pet effectiveness, Lifesteal/heal. Below it:
   "Equipped weapon": damage per hit before -> after (Zone Boost included) and the scaling grades.
 - **Bottom:** `Confirm (N Gold)` (disabled if not enough Gold, with a "Not enough Gold" toast),
   `Reset pending`, `Respec (X Diamonds)` with confirm popup.
 - Server: `Net.request("TrainAttributes", { Vigor = 2, ... })` -> validates keys, integers >= 0, caps,
   total cost (computed point by point), Gold >= cost, charges and applies atomically, saves, replies.
   `Net.request("RespecAttributes")` -> validates Diamonds, resets.

B1. EGGS
 - An egg item = `{ uid, zone = 1..12, rarity = 1..8 }`. Eggs come from enemy loot (loot system built
   later; here use admin `giveEgg`). Zone egg looks: one egg model per zone (12), a recolored egg with a
   pattern fitting the zone, plus a rarity glow ring.
 - Hatch location: **Egg Station in the hub** (and the Pets window has a "Hatch" tab that opens the same
   hatch screen from anywhere). Hatching a loot egg is free.
 - Result: a random pet from that zone's pool of 6 species (uniform) with **the egg's rarity**
   (guaranteed). Rebirth Shop `EggLuck`: after the rarity is decided, with probability `5% x level` the
   pet is one tier rarer (max Secret).
 - **Premium eggs** (Shop -> Diamonds tab and Egg Station): price `10 + 4 x zone` Diamonds, per zone
   (Z1 14 ... Z12 58). Rarity random with the weapon odds table (50, 28, 13, 6, 2.2, 0.7, 0.09, 0.01 %),
   same EggLuck rule. Only zones the player has unlocked can be bought; locked zones show the black
   silhouette with "?" like the weapon shop.
 - Storage: max 30 eggs. If an egg drops while full, it is auto-sold for
   `rarityMult x 100 x 10^(zone-1)` Gold (rarityMult from weapon doc) with a toast.
 - Hatch screen: egg appears, wobbles (speeds up), cracks, bursts; the pet pops out with name,
   species, rarity banner (reuse the rarity effect levels of the case opening), its stats and bonus.
   Buttons: Equip (if a slot is free), Hatch next, Close. "Hatch All" hatches every egg at once with a
   summary grid. A Fast mode follows the Settings "Fast open".
 - Eggs are lost on Rebirth.

B2. PETS
 - A pet = `{ uid, id (species), rarity = 1..8, premium = false }`.
 - **Stats:** each species has 2 **main stats** and 1 **unique bonus**. Main stat value by rarity
   (applies to each of its two main stats):
   Common +2% | Uncommon +4% | Rare +7% | Epic +11% | Legendary +16% | Mythic +23% | Divine +32% | Secret +45%.
   Stat meaning: Gold = Gold Gain % ; HP = Max HP % ; Attack = damage % ; Speed = move speed % (shares
   the +40% hard cap) ; Defense = Defense points %.
   Unique bonus value = **25% of the rarity's main value** (Legendary 4%, Secret 11.25%).
 - **Faith** multiplies all pet values (A4).
 - **Unique bonus types:** Trophy Value (+% Gold when selling trophies) | Crit Damage (+%) |
   Regeneration (+value x 0.05% Max HP per second) | Boss Slayer (+% damage to mini-bosses and bosses) |
   Loot Luck (+% loot drop chance, multiplicative) | Diamond Luck (+% relative diamond drop chance).
 - **Slots:** 3 equipped pets by default; the Extra Pet Slots game pass adds 2 (max 5). Max 3 pets
   FOLLOW the player visually (the first 3 equipped); all equipped pets give their stats.
 - Storage: 60 pets. Release (sell) a pet for `rarityMult x 150 x 10^(zone-1)` Gold. A locked pet cannot
   be released. If storage is full, hatching is blocked with a toast.
 - **Rebirth:** all pets are lost EXCEPT premium pets (bought with Robux).
