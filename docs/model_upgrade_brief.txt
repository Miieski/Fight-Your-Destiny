 2. STYLE TARGET: BETWEEN LOW-POLY AND REALISTIC
---------------------------------------------------------------------
 - Believable real-world shapes and proportions (planked wood, riveted metal, cut stone, woven straw,
   folded cloth), with clean faceted geometry and light bevels. Not photoreal, not noisy, not cartoon-flat.
 - Keep each model's MAIN colors recognizable (orange crates, red well roof, blue/white diamond awning, cyan
   fountain water...) and the map's bright, friendly palette. Add subtle variation: darker crevices, lighter
   worn edges, gentle gradients, small wear. Do NOT recolor the world.
 - Consistency: before modeling, write a **Prop Style Guide** in `Blender/Props/README.txt` with hex values
   for the shared material families (wood light/mid/dark, iron, brass/gold, stone light/dark, moss, cloth
   reds/blues/greens/orange, straw, bone), one bevel size ratio (about 2-3% of the object's smallest dimension),
   and the shared textures. All 19 models must use this guide so they look like one family.
 - Materials: `SurfaceAppearance` (ColorMap + NormalMap + Roughness/Metalness when useful) at 512 px (1024
   only for the fountain and the stalls). **Share tileable textures per material family** (wood, metal, stone,
   cloth, straw) across models to save memory, plus vertex colors for variation. Emissive parts (flames,
   gems, crystals, lantern glass, coals) are SEPARATE meshes/parts so lights and glow can be tuned.

 5. PIPELINE, TOOLS AND BUDGETS (MIXED METHOD)
---------------------------------------------------------------------
 STUDIO-BUILT (simple props): lamp_post, crate, barrel, mallet, lantern, laundry_rack, and the frame
 (posts, counter, backboard) of the stalls if cleaner in Studio. Rules: <= 40 Parts per small prop
 (<= 80 for a stall frame), grouped in a Model with a PrimaryPart, Anchored, CanTouch false, CanQuery false
 on decorative parts, `CastShadow` only for large parts, `Material` + SurfaceAppearance for wood/metal
 textures. If a Studio prop needs more parts than allowed, merge it into one MeshPart through Blender.
 BLENDER-BUILT (complex shapes): fountain, egg_nest, rowboat, minecart, skull_bones, scarecrow, clam_pearl,
 anvil_forge, well, chest, and the awnings, display items and gems of the stalls (weapons, shield, axe,
 trophy, crystal ball, diamonds).
 If the agent judges a different method gives a clearly better result, it may switch a prop and note why.
 Blender rules (same as docs/weapon_modeling_brief.txt):
 - Real-world scale in meters, 1 stud = 0.28 m; apply transforms; correct normals; clean UVs, no overlapping
   islands; no n-gons on the final mesh; origin and axis convention from Blender/Weapons/README.txt.
 - Triangle budgets: small props 300-1,500 | medium 1,500-4,000 | large (fountain, stalls, well, forge) up to
   8,000. One mesh per material family when possible; <= 4 materials per model.
 - Files: `Blender/Props/<propId>.blend` (source of truth, packed or `textures/` next to it),
   `Blender_Exports/Props/<propId>.fbx` (ONE FBX per prop containing all its meshes named
   `<propId>_<part>`), `Previews/Props/<propId>_before_after.png`. Save after every prop. Update
   `props_manifest.csv`.
 - Export collision-friendly geometry: set `CollisionFidelity = Box` or `Hull` for big props in Studio, never
   PreciseConvexDecomposition on large meshes.
 STUDIO IMPORT: the owner imports the FBX files with Studio's Asset Manager -> Bulk Import (you cannot do it
 yourself unless an approved route exists). Write `tools/ApplyPropMeshes.luau`: after the import it finds
 each imported model by file name, builds `ServerStorage.MapProps.<propId>` from it (anchors the parts, sets
 PrimaryPart, applies the right Material/SurfaceAppearance, adds the lights/emitters/attachments from
 `Config/PropFX.luau`, tags it) and then calls `SyncMapProps.run()`. Until the owner imports, the current
 models stay in place; Studio-built props are upgraded immediately. List the files to import in the report.

---------------------------------------------------------------------

   mobile: lights `Shadows = false`, small `Range`, low particle rates, <= 6 emitters in view.

   sparkle and gem glints, crystal ball shimmer, minecart crystal glow, a rare gold sparkle on the chest.
 - Sound: optional very quiet loops (fire crackle, fountain water, wind chime) through the Ambient SoundGroup,
   audible only within 25 studs, public/free audio only; list any missing sounds in the report.
